# Login Form in React JS
![alt text](<Login Form.PNG>)


# Project Overview
This project is a simple login form built using React.js. The form captures the user's email and password, validates the inputs, and displays an error message if the inputs do not meet the required format.

# Technologies Used
React.js (Frontend framework)

HTML & CSS (Styling)

React Hooks (useState for form state management)

Basic Validation (For email and password format checking)

# Installation
Follow these steps to get the project running on your local machine:

1.Clone the repository:
git clone https://github.com/melisamehe/login-form-react.git

2.Navigate into the project folder:
cd login-form-react

3,Install the required dependencies:
npm install

# Usage

1.After installation, you can start the development server by running:
npm start

2.Open the browser and go to:
http://localhost:3000

3.You should see the login form rendered on the page.
